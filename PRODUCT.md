# Personal Atlas

## Product
A public research portfolio for Jiangnan, focused on scientific machine learning, engineering computation, crack dynamics, parameter calibration, and research automation.

## Audience
- Technical recruiters evaluating depth, implementation quality, and communication.
- Research collaborators looking for methods, reproducible artifacts, and complementary expertise.
- Developers interested in reusable scientific-computing tools.

## Visitor mode
Experience. The research artifacts lead; interface chrome recedes.

## Primary outcome
Within ten seconds, a visitor should understand the research territory and find one representative project worth inspecting. The primary action is opening a project; the secondary action is contacting Jiangnan.

## Product truth
- Public GitHub repositories are the source of evidence.
- Real outputs, code, documentation, and reproducibility matter more than broad capability claims.
- Private repositories and unverified results must never appear.

## Constraints
- Static HTML, CSS, and small vanilla JavaScript only.
- Hosted on GitHub Pages.
- Core content remains readable without JavaScript.
- Chinese-first copy with concise English project names.
- Responsive from 320px to wide desktop.
