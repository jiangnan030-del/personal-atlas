# Personal Atlas

Jiangnan 的个人网站 MVP：产品、AI 与体验设计。

## 特性

- Fast / Explore 双层体验
- 响应式能力图谱
- 项目 Story / Data / Method 证据模式
- 本地 Personal AI 交互演示
- Now 页面与联系路径
- 键盘导航、reduced-motion、语义化 HTML
- 无框架、零构建依赖，可直接部署

## 本地运行

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080`。

## 部署

可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或 Vercel。
